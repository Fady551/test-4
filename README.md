# CodeHub — منصة مشاركة الأكواد

مشروع Next.js كامل (واجهة + قاعدة بيانات + تسجيل دخول) لمنصة نشر أكواد للمبرمجين، مبني على تصميم لوحة التحكم الأصلي.

## المكوّنات

- **Next.js 14** (App Router) — الواجهة والـ API
- **PostgreSQL + Prisma** — قاعدة البيانات (المستخدمين، الأكواد، الإعجابات، التعليقات، الإحصائيات اليومية)
- **NextAuth (Credentials)** — تسجيل الدخول بكلمة مرور مشفّرة (bcrypt)
- **Tailwind CSS** — نفس تصميم الملف الأصلي (بنفسجي/أصفر، RTL، خط Cairo)

كل الإحصائيات (مشاهدات، إعجابات، تحميلات، نسخ) أصبحت **حقيقية** ومحسوبة من قاعدة البيانات لحظيًا، بدل الأرقام العشوائية في النسخة الأولى.

---

## 1) التشغيل محليًا

```bash
npm install
cp .env.example .env         # ثم عدّل القيم بداخله (مهم: .env وليس .env.local)
npm run db:push              # ينشئ الجداول في قاعدة البيانات
npm run seed                 # (اختياري) بيانات تجريبية: demo@example.com / password123
npm run dev
```

يحتاج مشروعك قاعدة بيانات PostgreSQL شغالة أثناء التطوير المحلي أيضًا (أسهل حل: أنشئ مشروع مجاني على [neon.tech](https://neon.tech) واستخدم رابطه في `.env`).

## 2) النشر على Vercel

### أ) أنشئ قاعدة البيانات

1. من [vercel.com](https://vercel.com) → افتح مشروعك (أو أنشئ مشروع جديد بعد رفع الكود) → تبويب **Storage**.
2. اختر **Create Database** → **Postgres** (تكامل Neon المدمج في Vercel).
3. بعد الإنشاء، اربط قاعدة البيانات بمشروعك (Connect Project) — هيضيف تلقائيًا المتغيرات `DATABASE_URL` و `DIRECT_URL` (أو أسماء قريبة منها؛ لو الأسماء مختلفة، انسخ القيم وسمّها بنفس أسماء `.env.example`) في إعدادات المشروع.

### ب) ارفع الكود

```bash
git init
git add .
git commit -m "منصة نشر الأكواد - أول نسخة"
git remote add origin <رابط-مستودعك-على-GitHub>
git push -u origin main
```

ثم من Vercel: **Add New Project** → اختر المستودع → Import.

### ج) متغيرات البيئة على Vercel

في **Settings → Environment Variables** أضف (لو مش مضافة تلقائيًا من ربط قاعدة البيانات):

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | من تبويب Storage الخاص بقاعدة البيانات |
| `DIRECT_URL` | من نفس المكان (بعض مزودي Postgres يوفرونه لعمليات الـ migrate) |
| `NEXTAUTH_SECRET` | نص عشوائي — ولّده بـ `openssl rand -base64 32` |
| `NEXTAUTH_URL` | رابط موقعك بعد النشر، مثل `https://test.vercel.app` |

### د) أنشئ جداول قاعدة البيانات على الإنتاج

بعد أول نشر ناجح، شغّل مرة واحدة من جهازك (وأنت متصل بنفس `DATABASE_URL` بتاع الإنتاج داخل `.env.local` مؤقتًا):

```bash
npm run db:push
```

هيقرأ `prisma/schema.prisma` وينشئ كل الجداول في قاعدة بيانات الإنتاج.

### هـ) أعد النشر

اضغط **Redeploy** من لوحة Vercel، أو ادفع أي كوميت جديد — هيبني المشروع وهو متصل بقاعدة البيانات.

## 3) هيكل المشروع

```
app/
  page.js                 الصفحة الرئيسية (قائمة الأكواد)
  login/, register/       تسجيل الدخول وإنشاء حساب
  publish/                نشر كود جديد
  project/[id]/           صفحة تفاصيل الكود + التعليقات
  saved/                  المحفوظات
  dashboard/              لوحة التحكم (إحصائيات حقيقية + إدارة التعليقات)
  api/                    كل نقاط الـ API (مشاريع، تعليقات، إعجاب، حفظ، تتبع، لوحة التحكم)
components/               Sidebar, Topbar, Shell, ProjectCard
lib/                      prisma client, auth config, دوال تنسيق
prisma/schema.prisma      تعريف قاعدة البيانات
```

## 4) نقاط أمان ومحتوى مهمة (لازم تراجعها قبل الإطلاق الفعلي)

- ✅ فيه فلتر كلمات مفتاحية أساسي (`app/api/projects/route.js`) يرفض أكواد فيها كلمات زي keylogger/ddos tool، لكن **ده خط دفاع أول بسيط جدًا** ومش بديل عن مراجعة بشرية.
- ✅ فيه إقرار إجباري عند النشر يوافق عليه المستخدم بعدم مخالفة القانون أو الخصوصية.
- ✅ فيه نظام إبلاغ عن التعليقات + حذف/إخفاء لصاحب الكود.
- ⚠️ محتاج تضيف **صفحة شروط استخدام وسياسة خصوصية** حقيقية (فيها معلومات التواصل، آلية الإبلاغ، وحدود المسؤولية) قبل ما تفتح الموقع للعامة.
- ⚠️ ممكن تضيف لوحة أدمن منفصلة (فيه أساس لها في قاعدة البيانات عبر `isAdmin` على جدول `User`) لمراجعة البلاغات وحذف أي كود مخالف تم الإبلاغ عنه.
- ⚠️ لو الموقع هيستقبل عدد كبير من المستخدمين، فكّر في إضافة Rate Limiting على نقاط النشر والتعليقات لمنع الإسبام.

## 5) الخطوات القادمة المقترحة

- صفحة بروفايل عامة لكل مستخدم (بأكواده المنشورة)
- بحث بلغة برمجة/وسم محدد كفلتر منفصل بدل النص الحر فقط
- لوحة أدمن كاملة لمراجعة البلاغات وحظر المستخدمين
- رفع الكود كملف بدل اللصق (مفيد للمشاريع متعددة الملفات)
